단편 소설 웹사이트에 템플릿 시스템을 구현해주세요. 각 소설마다 HTML 파일을 따로 만드는 대신, 내용과 디자인을 분리하여 소설 내용만 쉽게 추가하고 편집할 수 있도록 만들어주세요.

요구사항:
1. 소설 내용은 JSON 파일로 분리 (제목, 저자, 언어, 내용 텍스트)
2. 공통 HTML 템플릿 하나를 모든 소설에 적용
3. JavaScript로 소설 데이터를 불러와 템플릿에 적용
4. 기존 디자인과 스타일은 그대로 유지
5. 소설 내용만 수정해도 전체 레이아웃과 디자인은 유지되어야 함
6. 다국어 지원 (한국어/영어)
7. URL 매개변수로 소설 선택 가능 (예: ?story=the-last-leaf)

구현 결과물:
1. 템플릿 HTML 파일 1개
2. 소설 내용 JSON 파일들 (소설별로 1개씩)
3. JavaScript 로더 스크립트
4. CSS는 기존 것 활용
5. 메인 페이지에서 소설 목록 표시 및 링크

이렇게 하면 나중에 소설 추가할 때 HTML 구조와 디자인을 신경 쓰지 않고 내용 파일만 추가하면 됩니다.

현재 우리 사이트는 소설마다 각각 HTML 파일을 만들고 있어요. 워드프레스나 블로그처럼, 소설 내용만 추가하면 디자인이 자동으로 적용되는 방식으로 바꾸고 싶습니다. 각 소설의 내용과 메타데이터(제목, 저자 등)는 JSON 파일로 분리하고, JavaScript로 이 내용을 불러와 공통 템플릿에 표시하는 방식으로 구현해주세요.
다음 기능도 추가해주세요:
1. 목차 자동 생성 기능
2. 폰트 크기 조절 옵션
3. 밝은/어두운 테마 전환 기능
4. 모바일 최적화

이 작업은 기존 기능을 유지하면서 내용 관리만 쉽게 하는 것이 목표입니다. 현재 파일 구조를 가능한 적게 변경하면서 가장 빠르게 구현할 수 있는 방법으로 진행해주세요.
