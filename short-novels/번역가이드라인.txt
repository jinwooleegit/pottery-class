[소설 번역 가이드라인]

1. 번역 원칙
- 영어 원문에 최대한 충실하게 번역
- 문장 구조와 표현을 가능한 한 원문과 동일하게 유지
- 불필요한 의역이나 추가 설명 지양
- 원문의 비유와 이미지를 그대로 살리기
- 문학적 표현과 뉘앙스 보존

2. 파일 구조
- HTML 파일명: stories/[소설-제목]/original.html
- 각 문단을 story-section으로 구분
- 각 섹션 내에서 한글 번역을 먼저, 영어 원문을 나중에 배치
- meta 섹션에 원제목, 작가, 최초 출간연도 포함

3. HTML 구조
```html
<div class="story-section">
    <div class="korean">
        <p>[한글 번역]</p>
    </div>
    <div class="english">
        <p>[영어 원문]</p>
    </div>
</div>
```

4. 스타일링
- 한글: Noto Serif KR, serif 폰트 사용
- 영어: Crimson Text, serif 폰트 사용
- 각 문단 사이 적절한 여백 유지
- 한글과 영어 문단 사이 구분선으로 분리

5. 메타 정보
- 제목은 "한글 제목 (영어 제목)" 형식으로 표시
- 작가 이름은 원어와 한글 병기
- 번역 정보 푸터에 원문 출처와 번역 원칙 명시

6. 품질 관리
- 전문 용어나 고유명사는 정확성 확인
- 시대적 배경을 고려한 적절한 어휘 선택
- 문장 호응과 문법적 정확성 검토
- 전체적인 가독성과 일관성 유지
