1주차: 장식의 기초와 도구 활용

강의 스크립트

안녕하세요. 오늘부터는 도예의 세 번째 단계인 '장식 단계'를 시작하겠습니다. 첫 주차에서는 장식의 기본 원리와 도구 활용법에 대해 배워보도록 하겠습니다.

1. 장식의 의미와 목적

도예에서 장식은 작품에 예술성과 개성을 부여하는 중요한 과정입니다.

장식의 역할: - 미적 가치 향상 - 작품의 개성 표현 - 기능성 보완 - 문화적 의미 전달

장식이 필요한 시점: - 가죽 경도 상태 - 완전 건조 전 - 특수 기법별 적정 시점

2. 기본 장식 도구의 이해

각 도구의 특성과 활용법을 배워보겠습니다.

[도구 소개] 1) 조각도 - 다양한 형태와 크기 - 선각과 양각용 - 날의 관리법

2) 문양도장 - 전통 문양 - 현대적 패턴 - 압인 강도 조절

3) 붓과 스펀지 - 붓의 종류와 특성 - 스펀지의 활용 - 도구 관리법

3. 문양의 기초 원리

기본적인 문양 구성과 원리를 이해해보겠습니다.

기본 문양의 종류: - 기하학적 문양 - 자연물 문양 - 추상 문양 - 복합 문양

문양 구성의 원리: - 반복과 리듬 - 대칭과 균형 - 강조와 변화 - 통일성과 조화

4. 기본 장식 기법

가장 기본적인 장식 기법들을 배워보겠습니다.

1) 선각 기법 - 도구 잡는 법 - 선의 깊이 조절 - 곡선 표현 방법

2) 양각 기법 - 도구 선택 - 깊이 조절 - 입체감 표현

3) 압인 기법 - 도구 활용 - 강도 조절 - 반복 패턴

실습 지도

이제 실습을 통해 기본적인 장식 기법을 익혀보겠습니다.

[실습 1] 기본 선각 실습 1. 직선 그리기 2. 곡선 표현 3. 패턴 만들기

[실습 2] 압인 기법 실습 1. 단일 문양 2. 반복 패턴 3. 조합 문양

각자 준비된 시편으로 실습을 진행해주세요. 도구 사용이 어려운 부분이 있다면 질문해주시기 바랍니다.
