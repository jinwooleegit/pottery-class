3주차: 슬립 장식과 색소지 활용

강의 스크립트

안녕하세요. 오늘은 슬립을 이용한 장식 기법과 색소지를 활용한 표현 방법에 대해 배워보도록 하겠습니다.

1. 슬립의 이해

슬립은 점토를 물에 풀어 만든 액상의 재료입니다.

슬립의 특성: 1) 물리적 특성 - 점도와 농도 - 건조 수축률 - 접착성

2) 제작 방법 - 원료 선택 - 배합 비율 - 숙성과 보관

3) 색상 조절 - 산화물 첨가 - 안료 혼합 - 발색 테스트

2. 슬립 장식 기법

다양한 슬립 장식 기법을 배워보겠습니다.

1) 붓 장식 - 붓의 종류와 선택 - 선의 표현 - 면의 채색 - 농담 표현

2) 흘림 기법 - 흘림 속도 조절 - 방향성 활용 - 중첩 효과 - 우연성 활용

3) 스크래피토 - 바탕 슬립 바르기 - 건조 시점 파악 - 긁기 기법 - 질감 표현

3. 색소지의 활용

색소지를 이용한 다양한 표현 방법을 알아보겠습니다.

색소지의 제작: 1) 재료 준비 - 기본 소지 선택 - 안료 선택 - 첨가물 준비

2) 배합 방법 - 안료 비율 - 혼합 순서 - 숙성 시간

3) 색상 관리 - 샘플 제작 - 기록 관리 - 보관 방법

4. 혼합 기법

슬립과 색소지를 함께 활용하는 방법을 배워보겠습니다.

1) 마블링 기법 - 색상 조합 - 패턴 만들기 - 효과 조절

2) 상감 기법 - 문양 새기기 - 색소지 채우기 - 면 정리

3) 면치기 기법 - 색소지 판 제작 - 문양 재단 - 접착과 마감

실습 지도

이제 실습을 통해 다양한 기법을 적용해보겠습니다.

[실습 1] 슬립 장식 1. 슬립 제작 2. 붓 장식 연습 3. 흘림 기법 시도 4. 스크래피토 실습

[실습 2] 색소지 작업 1. 색소지 제작 2. 마블링 시도 3. 상감 기법 실습 4. 면치기 작업

각자 준비된 시편으로 실습을 진행해주세요. 기법 적용 시 어려운 점이 있다면 질문해주시기 바랍니다.
