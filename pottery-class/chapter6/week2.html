2주차: 포트폴리오 제작

강의 스크립트

안녕하세요. 이번 주차에서는 여러분의 작품과 제작 과정을 체계적으로 정리하는 포트폴리오 제작 방법에 대해 배워보도록 하겠습니다.

1. 포트폴리오 구성

효과적인 포트폴리오 구성 방법을 알아보겠습니다.

1) 기본 구성 - 작가 소개 - 작품 목록 - 제작 과정 - 기술 설명

2) 구성 요소 - 표지 디자인 - 목차 구성 - 섹션 구분 - 페이지 레이아웃

3) 내용 구성 - 작품 설명 - 기술 정보 - 제작 의도 - 발전 과정

2. 작품 사진 촬영

도예 작품을 효과적으로 촬영하는 방법을 배워보겠습니다.

1) 촬영 준비 - 장비 설정 - 배경 준비 - 조명 설치 - 작품 배치

2) 촬영 기법 - 각도 선택 - 빛 조절 - 초점 설정 - 구도 잡기

3) 이미지 편집 - 밝기 조정 - 색상 보정 - 크기 조절 - 품질 향상

3. 제작 과정 정리

작품 제작 과정을 체계적으로 정리하는 방법을 알아보겠습니다.

1) 과정 기록 - 단계별 사진 - 작업 일지 - 기술 노트 - 시간 기록

2) 자료 정리 - 스케치 - 도면 - 재료 정보 - 기법 설명

3) 문제 해결 - 시행착오 - 해결 방안 - 개선 과정 - 최종 결과

4. 작품 설명 작성

작품을 효과적으로 설명하는 글쓰기 방법을 배워보겠습니다.

1) 기본 정보 - 작품명 - 제작 연도 - 크기/재료 - 기법

2) 작품 해설 - 제작 의도 - 형태 설명 - 기술 특징 - 예술성

3) 전문적 기술 - 제작 기법 - 유약 정보 - 소성 조건 - 특수 효과

실습 지도

이제 실습을 통해 포트폴리오를 제작해보겠습니다.

[실습 1] 자료 준비 1. 작품 선별 2. 사진 촬영 3. 자료 정리 4. 내용 구성

[실습 2] 포트폴리오 제작 1. 레이아웃 작성 2. 내용 입력 3. 이미지 배치 4. 최종 점검

각자의 작품과 자료를 가지고 포트폴리오 제작을 시작해보세요. 궁금한 점이 있다면 질문해주시기 바랍니다.
