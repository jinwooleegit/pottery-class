3주차: 재벌구이의 원리와 실제

강의 스크립트

안녕하세요. 이번 주차에서는 재벌구이의 기본 원리와 실제 적용 방법에 대해 배워보도록 하겠습니다.

1. 재벌구이의 원리

재벌구이의 기본 원리와 과정을 이해해보겠습니다.

1) 유약의 용융 - 용융 온도 - 용융 과정 - 표면 장력 - 광택 형성

2) 소지와의 반응 - 계면 반응 - 침투 현상 - 결합 강도 - 열팽창 관계

3) 분위기 영향 - 산화/환원 - 가스 발생 - 색상 변화 - 질감 형성

2. 온도와 시간 관리

재벌구이의 온도와 시간 관리 방법을 배워보겠습니다.

1) 승온 관리 - 초기 승온 - 중간 단계 - 최고 온도 - 승온 속도

2) 유지 시간 - 온도별 유지 - 목적별 조절 - 효과 관찰 - 시간 계산

3) 냉각 관리 - 자연 냉각 - 급속 냉각 - 단계별 냉각 - 뒤틀림 방지

3. 가마 적재 방법

효율적이고 안전한 가마 적재 방법을 알아보겠습니다.

1) 기본 원칙 - 공간 활용 - 열순환 고려 - 안전 거리 - 무게 분산

2) 적재 기술 - 받침대 사용 - 쌓기 방법 - 간격 조절 - 고정 방법

3) 특수 상황 - 대형 작품 - 복잡한 형태 - 민감한 유약 - 혼합 적재

4. 냉각 과정 관리

재벌구이 후 냉각 과정의 관리 방법을 배워보겠습니다.

1) 냉각 단계 - 고온 구간 - 중온 구간 - 저온 구간 - 상온 복귀

2) 주의사항 - 열충격 방지 - 균열 예방 - 변형 관리 - 안전 확보

3) 품질 관리 - 외관 검사 - 결함 확인 - 기록 관리 - 분석 평가
