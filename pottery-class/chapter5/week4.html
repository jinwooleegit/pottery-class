4주차: 특수 효과와 문제 해결

강의 스크립트

안녕하세요. 이번 주차에서는 특수한 유약 효과와 재벌구이 과정에서 발생할 수 있는 문제점들의 해결 방법에 대해 배워보도록 하겠습니다.

1. 결정유와 특수유

특별한 효과를 내는 유약들의 특성과 사용법을 알아보겠습니다.

1) 결정유 - 결정 생성 원리 - 온도 관리 - 냉각 조절 - 효과 예측

2) 매트유 - 표면 질감 - 조성 특징 - 적용 방법 - 효과 조절

3) 특수 효과유 - 진사유 - 천목유 - 철사유 - 유리질유

2. 환원과 산화 효과

가마 분위기에 따른 다양한 효과를 배워보겠습니다.

1) 환원 소성 - 분위기 조성 - 연료 조절 - 산소 관리 - 효과 특성

2) 산화 소성 - 공기 공급 - 온도 관리 - 색상 변화 - 표면 특성

3) 중성 소성 - 균형 조절 - 안정성 - 재현성 - 활용 범위

3. 일반적인 문제점

재벌구이 과정에서 자주 발생하는 문제들을 살펴보겠습니다.

1) 유약 결함 - 핀홀 - 갈라짐 - 박리 - 흐름 과다

2) 소성 문제 - 변형 - 붙음 - 색상 불량 - 질감 이상

3) 구조적 문제 - 균열 - 파손 - 뒤틀림 - 접합 불량

4. 해결 방안과 예방

문제 해결과 예방을 위한 방법을 배워보겠습니다.

1) 원인 분석 - 현상 관찰 - 조건 검토 - 기록 확인 - 실험 분석

2) 해결 방법 - 유약 조정 - 소성 조절 - 적재 개선 - 공정 수정

3) 예방 관리 - 품질 관리 - 조건 표준화 - 기록 유지 - 정기 점검

실습 지도

이제 실습을 통해 특수 효과 구현과 문제 해결을 해보겠습니다.

[실습 1] 특수 효과 1. 결정유 시유 2. 환원 소성 3. 효과 관찰 4. 결과 분석

[실습 2] 문제 해결 1. 문제 확인 2. 원인 분석 3. 해결 시도 4. 예방 계획

각자 준비한 시편으로 다양한 효과를 시도해보세요. 문제가 발생하면 함께 해결 방법을 찾아보도록 하겠습니다.
