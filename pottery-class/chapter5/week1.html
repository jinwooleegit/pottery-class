1주차: 유약의 이해와 시유 준비

강의 스크립트

안녕하세요. 오늘부터는 도예의 다섯 번째 단계인 '시유와 재벌구이'를 시작하겠습니다. 첫 주차에서는 유약의 기본 특성과 시유를 위한 준비 과정에 대해 배워보도록 하겠습니다.

1. 유약의 성분과 특성

유약의 기본 구성과 특성을 이해해보겠습니다.

1) 기본 성분 - 융제(장석, 석회석) - 내화성 물질(규석, 알루미나) - 안정제(카올린, 점토) - 착색제(금속 산화물)

2) 물리적 특성 - 용융점 - 점도 - 표면장력 - 열팽창계수

3) 화학적 특성 - 산화물 조성 - 반응성 - 안정성 - 내구성

2. 유약의 종류와 선택

다양한 유약의 종류와 선택 기준을 알아보겠습니다.

1) 투명유 - 기본 조성 - 적용 범위 - 특성과 효과 - 선택 기준

2) 불투명유 - 조성의 특징 - 사용 목적 - 효과와 특성 - 적용 방법

3) 특수유 - 결정유 - 매트유 - 진사유 - 청자유

3. 시유 도구와 준비

시유에 필요한 도구와 준비 과정을 배워보겠습니다.

1) 기본 도구 - 시유 통 - 붓과 스프레이 - 집게와 받침 - 측정 도구

2) 유약 준비 - 비중 조절 - 체질과 여과 - 보관 방법 - 재활용

3) 작업 환경 - 작업대 설치 - 환기 시설 - 보호 장비 - 청소 도구

4. 작품 표면 처리

시유 전 작품 표면 처리 방법을 알아보겠습니다.

1) 표면 정리 - 먼지 제거 - 요철 처리 - 면 다듬기 - 이물질 제거

2) 흡수도 조절 - 수분 함량 - 표면 습도 - 건조 상태 - 흡수 테스트

3) 문양 처리 - 음각 부분 - 양각 부분 - 접합 부위 - 특수 효과

실습 지도

이제 실습을 통해 유약 준비와 표면 처리를 해보겠습니다.

[실습 1] 유약 준비 1. 비중 측정 2. 체질 과정 3. 보관 방법 4. 품질 관리

[실습 2] 표면 처리 1. 표면 정리 2. 흡수도 확인 3. 문양 부분 처리 4. 최종 점검

각자 준비한 작품으로 실습을 진행하겠습니다. 유약 준비나 표면 처리에 어려움이 있다면 질문해주세요.
