4주차: 다양한 초벌구이 기법

강의 스크립트

안녕하세요. 이번 주차에서는 다양한 초벌구이 기법과 실험적인 시도들에 대해 배워보도록 하겠습니다.

1. 전통 소성 기법

우리나라의 전통적인 초벌구이 방법을 살펴보겠습니다.

1) 장작 가마 - 가마의 구조 - 온도 조절 방법 - 불의 관리 - 전통적 특징

2) 재임 방법 - 작품 배치 - 공간 활용 - 열 순환 고려 - 전통적 지혜

3) 소성 과정 - 불때기 순서 - 시간 관리 - 경험적 판단 - 결과물 특성

2. 현대적 접근 방법

현대 기술을 활용한 초벌구이 방법을 알아보겠습니다.

1) 프로그램 소성 - 자동화 시스템 - 정밀 제어 - 데이터 관리 - 효율성 향상

2) 신기술 적용 - 센서 활용 - IoT 기술 - 원격 모니터링 - 자동 제어

3) 에너지 효율 - 단열 기술 - 열 회수 - 연료 절감 - 환경 고려

3. 실험적 시도

새로운 가능성을 탐구하는 실험적 접근법을 배워보겠습니다.

1) 온도 실험 - 변화 구간 - 유지 시간 - 냉각 속도 - 효과 관찰

2) 재료 실험 - 혼합 소지 - 첨가물 효과 - 반응 관찰 - 물성 변화

3) 기법 실험 - 적재 방식 - 분위기 조절 - 복합 기법 - 새로운 시도

4. 결과물 분석

다양한 소성 방법에 따른 결과를 분석해보겠습니다.

1) 물리적 특성 - 강도 측정 - 기공률 검사 - 수축률 확인 - 변형도 평가

2) 표면 특성 - 색상 변화 - 질감 관찰 - 균일성 검사 - 결함 분석

3) 활용 가능성 - 유약 적용성 - 재벌구이 적합성 - 특수 효과 - 예술적 가치

실습 지도

이제 실습을 통해 다양한 소성 기법을 시도해보겠습니다.

[실습 1] 전통과 현대 1. 전통 기법 체험 2. 현대 기법 적용 3. 결과 비교 4. 장단점 분석

[실습 2] 실험적 시도 1. 실험 계획 2. 조건 설정 3. 실험 진행 4. 결과 분석

각자의 창의성을 발휘하여 새로운 가능성을 탐구해보시기 바랍니다. 실험 과정에서 궁금한 점이 있다면 질문해주세요.
