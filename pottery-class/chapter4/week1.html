1주차: 초벌구이의 원리와 가마의 이해

강의 스크립트

안녕하세요. 오늘부터는 도예의 네 번째 단계인 '초벌구이'를 시작하겠습니다. 첫 주차에서는 초벌구이의 기본 원리와 가마의 구조에 대해 배워보도록 하겠습니다.

1. 초벌구이의 의미와 목적

초벌구이는 도예 작품의 기본적인 강도를 높이고 유약 시유를 위한 준비 단계입니다.

초벌구이의 역할: 1) 물리적 변화 - 강도 향상 - 기공 형성 - 수축 완료

2) 화학적 변화 - 결정수 제거 - 유기물 소실 - 광물 변화

3) 시유 준비 - 흡수율 조절 - 표면 안정화 - 작업성 향상

2. 가마의 종류와 특성

초벌구이에 사용되는 다양한 가마의 종류와 특성을 알아보겠습니다.

1) 전기가마 - 온도 조절의 정확성 - 산화 분위기 유지 - 조작의 편리성 - 에너지 효율

2) 가스가마 - 온도 상승 속도 - 분위기 조절 가능 - 열효율 - 운영 비용

3) 기타 가마 - 전통 가마 - 실험용 가마 - 특수 목적 가마

3. 가마의 구조와 작동 원리

가마의 기본 구조와 작동 원리를 이해해보겠습니다.

1) 기본 구조 - 발열체/버너 - 내화벽 - 단열재 - 제어 장치

2) 열 순환 - 대류 - 전도 - 복사 - 배기

3) 온도 제어 - 온도계 - 제어 시스템 - 프로그램 설정 - 모니터링

4. 안전 수칙과 주의사항

가마 작업 시 반드시 지켜야 할 안전 수칙을 배워보겠습니다.

1) 작업 전 점검 - 전기 시설 - 가스 설비 - 환기 시설 - 소화 장비

2) 작업 중 주의사항 - 보호구 착용 - 온도 확인 - 이상 징후 감지 - 비상 조치

3) 작업 후 관리 - 전원/가스 차단 - 냉각 확인 - 청소와 정리 - 기록 작성

실습 지도

이제 실습을 통해 가마의 기본 조작법을 익혀보겠습니다.

[실습 1] 가마 점검 1. 외관 검사 2. 내부 상태 확인 3. 제어 장치 테스트 4. 안전 장비 확인

[실습 2] 기본 조작 1. 전원/가스 공급 2. 온도 설정 3. 프로그램 입력 4. 비상 정지 훈련

각자 안전 수칙을 숙지하고 실습에 임해주시기 바랍니다. 조작이 어려운 부분이 있다면 반드시 질문해주세요.
