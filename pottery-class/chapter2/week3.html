3주차: 정형의 기본 원리

강의 스크립트

안녕하세요. 오늘은 도예에서 매우 중요한 과정인 정형의 기본 원리에 대해 배워보도록 하겠습니다.

1. 정형의 의미와 중요성

정형은 건조된 기물의 형태를 다듬고 완성하는 과정입니다.

정형의 목적: - 기물의 형태 완성 - 표면 질감 개선 - 두께 조절 - 안정성 향상

2. 정형 도구의 이해

각 도구의 특성과 용도를 이해하는 것이 중요합니다.

[도구 소개] 1) 정형칼 - 다양한 형태와 크기 - 용도별 특성 - 관리 방법

2) 스펀지 - 경도별 특징 - 사용 시점 - 세척과 보관

3) 나무 도구 - 형태별 용도 - 장단점 - 관리 방법

3. 정형 시점 판단

적절한 정형 시점을 판단하는 것은 성공적인 정형을 위해 매우 중요합니다.

정형 가능 상태의 특징: - 가죽 경도 상태 - 표면의 촉감 - 도구 자국의 회복력 - 작업 시 분진 발생 정도

[시연하며] 정형 시점 확인 방법: 1. 손톱으로 표면 긁어보기 2. 도구로 가볍게 눌러보기 3. 표면 광택 관찰하기

4. 기본 정형 기술

정형의 기본적인 기술들을 배워보겠습니다.

1) 바닥면 정형 - 수평 확보 방법 - 두께 조절 - 안정성 확인

2) 측면 정형 - 곡선 다듬기 - 두께 균일화 - 표면 정리

3) 구연부 정형 - 선의 완성 - 두께 조절 - 마감 처리

실습 지도

이제 실습을 통해 기본적인 정형 기술을 익혀보겠습니다.

[실습 1] 바닥면 정형 1. 수평 확인 2. 두께 측정 3. 정형 실시 4. 결과 확인

[실습 2] 측면 정형 1. 형태 관찰 2. 기준선 설정 3. 단계별 정형 4. 표면 마감

각자 준비된 기물로 실습을 진행해주세요. 어려운 부분이 있다면 질문해주시기 바랍니다.
