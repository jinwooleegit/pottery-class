제2장: 건조와 정형

3주차: 기본 정형 기법의 이해와 실습

강의계획서

학습목표

  • 기본적인 정형 기법의 원리를 이해한다
  • 다양한 정형 도구의 사용법을 익힌다
  • 작품의 특성에 맞는 정형 방법을 선택할 수 있다

준비물

  • 정형 도구 세트
    • 나무 칼
    • 와이어 도구
    • 스펀지
    • 깎기 도구
  • 반건조 상태의 시편
  • 물통과 스프레이
  • 측정 도구

강의 내용

  1. 정형의 기본 원리 (30분)
    • 정형의 의미와 목적
    • 적절한 정형 시기
    • 정형 시 주의사항
  2. 정형 도구 소개 및 사용법 (40분)
    • 도구별 특성과 용도
    • 도구 관리 방법
    • 안전한 사용법
  3. 기본 정형 기법 실습 (60분)
    • 바닥면 정형
    • 측면 정형
    • 모서리 처리
  4. 마무리와 평가 (20분)
    • 작품 점검
    • 보완점 토론

평가 포인트

  • 정형 도구를 올바르게 사용할 수 있는가
  • 작품의 형태를 정확하게 다듬을 수 있는가
  • 안전하고 깨끗하게 작업을 수행하는가

강의 스크립트

안녕하세요. 오늘은 기본적인 정형 기법에 대해 배워보도록 하겠습니다. 정형은 건조된 작품의 형태를 다듬고 완성도를 높이는 중요한 과정입니다.

정형의 의미와 목적:

  • 형태의 정교화: 의도한 형태에 더 가깝게 만들기
  • 표면 처리: 매끄럽게 하거나 질감 부여
  • 디테일 추가: 세부적인 장식이나 문양 작업

정형 작업을 시작하기 전에 가장 중요한 것은 작품의 건조 상태를 확인하는 것입니다. [시편을 보여주며] 이상적인 정형 시기는 '반건조 상태' 또는 '가죽 굳기 상태'라고 부르는 단계입니다.

반건조 상태의 특징:

  • 손으로 눌렀을 때 약간의 탄성이 있음
  • 표면이 약간 촉촉하나 손에 흙이 묻지 않음
  • 색상이 원래보다 약간 밝아진 상태

이제 정형 도구들을 살펴보겠습니다. [도구를 하나씩 보여주며]

1. 나무 칼

  • 용도: 큰 면적의 기본 정형
  • 특징: 부드러운 정형이 가능
  • 사용법: 일정한 각도로 긁어내기

2. 와이어 도구

  • 용도: 굴곡이 있는 부분의 정형
  • 특징: 다양한 곡면 작업에 적합
  • 사용법: 원하는 곡선을 따라 부드럽게 이동

3. 스펀지

  • 용도: 표면 마무리
  • 특징: 매끄러운 표면 처리 가능
  • 사용법: 적당한 수분을 머금고 문지르기

4. 깎기 도구

  • 용도: 세부 정형과 디테일 작업
  • 특징: 정교한 작업 가능
  • 사용법: 정확한 힘 조절이 중요

[실습 시작] 이제 실제로 정형 작업을 진행해보겠습니다. 먼저 바닥면부터 시작하겠습니다.

바닥면 정형 순서:

  1. 작품을 안전하게 뒤집어 놓기
  2. 나무 칼로 전체적인 평평도 확인
  3. 울퉁불퉁한 부분 제거
  4. 와이어 도구로 가장자리 다듬기
  5. 스펀지로 마무리

[시연하며] 바닥면을 정형할 때는 작품 전체의 균형을 고려해야 합니다. 한쪽으로 기울어지지 않도록 주의하세요.

다음은 측면 정형입니다:

  1. 전체적인 형태 확인
  2. 나무 칼로 큰 면적 정형
  3. 굴곡 부분은 와이어 도구 사용
  4. 깎기 도구로 세부 정형
  5. 스펀지로 표면 마무리

[주의사항을 설명하며] 정형 작업 시 주의할 점들입니다:

  • 한 번에 너무 많이 깎지 않기
  • 도구는 항상 깨끗하게 유지
  • 작업 중간중간 전체적인 형태 확인
  • 필요한 경우 스프레이로 수분 보충

모서리 처리는 작품의 완성도를 높이는 중요한 요소입니다. [시연하며] 모서리는 의도에 따라 날카롭게 또는 부드럽게 처리할 수 있습니다.

이제 각자 준비된 시편으로 실습을 진행해보겠습니다. 실습 중 궁금한 점이 있으면 언제든 질문해주세요.

[실습 진행 중 주의 사항]

  • 도구 사용 시 안전에 유의
  • 작업대 주변 정리 정돈
  • 필요 시 물 분무로 건조 방지
  • 정형 후 부스러기 즉시 처리
