4주차: 정형 기법의 실제

강의 스크립트

안녕하세요. 오늘은 지난 시간에 배운 정형의 기본 원리를 바탕으로, 다양한 형태의 기물에 정형 기법을 실제로 적용해보도록 하겠습니다.

1. 기물 형태별 정형 기법

기물의 형태에 따라 적절한 정형 기법을 선택하는 것이 중요합니다.

1) 원통형 기물 - 수직선 유지 방법 - 곡면의 균일성 확보 - 구연부 처리 기법

2) 볼 형태 기물 - 곡선의 균형감 확보 - 최대 지름 부위 처리 - 바닥 전환부 정형

3) 각진 형태 기물 - 면과 모서리 처리 - 각도 유지 방법 - 선의 날카로움 조절

2. 고급 정형 기술

보다 세밀하고 전문적인 정형 기술을 배워보겠습니다.

[시연하며] 고급 기술 소개: 1) 단차 정형 - 깊이 조절 - 선의 날카로움 - 균일성 확보

2) 음각 정형 - 도구 선택 - 깊이 조절 - 선의 흐름 유지

3) 질감 표현 - 도구별 효과 - 패턴 만들기 - 균일성 유지

3. 문제 해결 기술

정형 과정에서 발생할 수 있는 문제들과 해결 방법을 알아보겠습니다.

일반적인 문제와 해결책: 1) 균열 발생 - 원인 파악 - 응급 처치 - 예방법

2) 두께 불균형 - 측정 방법 - 보정 기술 - 예방책

3) 형태 왜곡 - 원인 분석 - 교정 방법 - 지지대 활용

4. 마감 처리

정형이 완료된 기물의 마감 처리 방법을 배워보겠습니다.

마감의 단계: 1. 거친 면 정리 2. 미세 흠집 제거 3. 최종 표면 처리

[시연하며] 마감 도구 활용: - 스펀지별 효과 - 천의 활용 - 물의 사용량

실습 지도

이제 실습을 통해 다양한 정형 기법을 적용해보겠습니다.

[실습 1] 기본형 다완 정형 1. 내면 곡선 정형 2. 외면 곡선 정형 3. 굽 처리 4. 마감

[실습 2] 각형 화병 정형 1. 면 정형 2. 모서리 처리 3. 구연부 정형 4. 마감

각자 준비된 기물로 실습을 진행해주세요. 정형 과정에서 발생하는 문제들은 바로 질문해주시기 바랍니다.

이번 장의 마지막 수업인 만큼, 건조와 정형 과정 전반에 대해 궁금한 점이 있다면 질문해주세요.

강의 계획서

학습목표

  • 기물의 형태에 따른 적절한 정형 기법을 선택할 수 있다
  • 고급 정형 기술을 이해하고 적용할 수 있다
  • 정형 과정의 문제를 해결할 수 있다
  • 기물의 최종 마감 처리를 할 수 있다

    • 각진 형태 기물
  • 정형 도구

  2. 고급 정형 기술 (40분)
    • 단차와 음각 정형

  3. 문제 해결 실습 (30분)

    • 단계별 마감
    • 도구 활용법

과제

  • 정형 기법별 특징과 주의사항 정리
  • 마감 처리 전후 비교 사진 제출
