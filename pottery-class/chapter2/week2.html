2주차: 건조 과정 관리

강의 스크립트

안녕하세요. 지난 시간에 배운 건조의 기본 원리를 바탕으로, 오늘은 실제 작품의 건조 과정을 효과적으로 관리하는 방법에 대해 배워보도록 하겠습니다.

1. 작품별 건조 방법

작품의 특성에 따라 적절한 건조 방법을 선택하는 것이 중요합니다.

1) 평면 작품 - 판 작업의 경우 평평한 면이 휘어지지 않도록 주의 - 석고판이나 목판 위에서 건조 - 뒤집어가며 균일하게 건조

2) 입체 작품 - 두께가 균일하지 않은 부분 주의 - 무게 중심을 고려한 지지대 사용 - 접합부 주변 특별 관리

3) 대형 작품 - 단계적인 건조 필수 - 부분별 건조 속도 조절 - 지지대 및 보조 도구 활용

2. 건조 속도 조절

건조 속도는 작품의 안전성에 직접적인 영향을 미칩니다.

[시연하며] 건조 속도 조절 방법: - 비닐 커버 사용: 완전 밀폐에서 부분 개방까지 단계적 조절 - 습도 조절: 주변에 물을 담은 용기 배치 - 통풍 조절: 선풍기나 환풍기의 세기와 방향 조절

3. 균열 방지 기술

균열은 건조 과정에서 가장 흔히 발생하는 문제입니다.

균열이 자주 발생하는 부위: - 두께 차이가 큰 부분 - 접합부 - 날카로운 모서리 - 바닥면

균열 방지를 위한 조치: - 위험 부위 습도 유지 - 부분별 건조 속도 조절 - 적절한 지지대 사용 - 정기적인 상태 점검

4. 건조 상태 점검

정기적인 상태 점검은 성공적인 건조를 위해 필수적입니다.

점검 항목: - 색상 변화 관찰 - 표면 촉감 확인 - 소리로 건조도 확인 - 무게 측정

[시연하며] 건조 상태 확인 방법: 1. 색상: 밝아지는 정도 확인 2. 촉감: 차가운 느낌이 없어짐 3. 소리: 마른 소리가 나는지 확인 4. 무게: 일정 간격으로 측정

실습 지도

이제 실습을 통해 다양한 작품의 건조 관리를 경험해보겠습니다.

준비된 작품들의 현재 상태를 확인해보겠습니다: 1. 판 작업: 건조 초기 단계 2. 물레 작업: 반 건조 상태 3. 코일 작업: 거의 건조된 상태

[실습 진행] 각 작품의 상태에 따라 적절한 건조 방법을 선택하고 적용해보세요. - 판 작업: 석고판 위에서 건조, 주기적으로 뒤집기 - 물레 작업: 부분적 비닐 커버 사용 - 코일 작업: 완전 개방 상태로 건조

각자 담당한 작품의 상태 변화를 기록하면서, 다음 수업까지 관리해주세요.

오늘은 작품별 건조 관리 방법과 균열 방지 기술에 대해 배웠습니다. 질문 있으신가요?
