# Cursor AI 작업 지시 기획서: 세상을 바꾼 명연설 50선

## 프로젝트 개요
**프로젝트명:** 세상을 바꾼 명연설 50선 웹사이트  
**목적:** 역사적 명연설을 시대별로 정리한 교육/참고 웹사이트 구축 후 PDF 전자책 제작  
**기술 스택:** HTML, CSS (JavaScript 최소화)  
**배포 방식:** GitHub Pages

## 1. 기본 구조 생성 요청

```
다음 파일 구조로 "세상을 바꾼 명연설 50선" 웹사이트의 기본 뼈대를 생성해주세요:

- index.html (메인 페이지)
- categories/
  - ancient-to-modern.html (고대~근대)
  - early-20th.html (20세기 전반)
  - mid-20th.html (20세기 중반)
  - late-20th.html (20세기 후반~현대)
  - asia-others.html (아시아 및 기타 지역)
- speeches/
  - speech-template.html (연설 페이지 템플릿)
- css/
  - main.css (기본 스타일시트)
  - responsive.css (반응형 스타일)
  - print.css (인쇄/PDF용 스타일)
- images/ (빈 폴더 생성)
- resources.html (참고자료 페이지)

모든 HTML 페이지에는 적절한 메타태그, 반응형 뷰포트 설정, 한국어 문자 인코딩을 포함해주세요.
```

## 2. 메인 페이지 구현 요청

```
index.html 파일에 다음 요소를 포함하는 메인 페이지를 구현해주세요:

1. 헤더 섹션:
   - 웹사이트 제목 "세상을 바꾼 명연설 50선"
   - 간략한 소개문 "역사를 바꾸고 세상에 영감을 준 50개의 명연설"

2. 내비게이션 메뉴:
   - 5개 카테고리(고대~근대, 20세기 전반, 20세기 중반, 20세기 후반~현대, 아시아 및 기타 지역)로 연결되는 링크
   - 참고자료 페이지 링크

3. 메인 컨텐츠:
   - 시대별 타임라인 형식으로 카테고리 소개
   - 각 카테고리별 대표 연설 1-2개 하이라이트

4. 푸터:
   - 저작권 정보 "© 2025 이진우"
   - 간략한 제작자 소개

반응형 디자인을 위한 CSS 클래스를 적절히 적용해주세요.
```

## 3. 스타일시트 구현 요청

```
main.css 파일에 다음 스타일 요소를 구현해주세요:

1. 전체 레이아웃:
   - 최대 너비 1200px, 중앙 정렬
   - 여백과 패딩의 일관된 적용
   - 그리드 또는 플렉스박스 기반 레이아웃

2. 타이포그래피:
   - 기본 글꼴: 'Noto Serif KR' (본문), 'Noto Sans KR' (제목)
   - 기본 글자 크기: 16px (본문)
   - 라인 높이: 1.6
   - 제목 계층 구조 (h1-h6) 스타일링

3. 색상 팔레트:
   - 기본 텍스트: #333333
   - 배경색: #f8f8f8
   - 주 강조색: #4a6da7
   - 보조 강조색: #a74a4a
   - 카테고리별 상징색 (5가지 다른 색상)

4. 내비게이션:
   - 상단 고정 메뉴
   - 호버 효과
   - 현재 페이지 표시

5. 타임라인 디자인:
   - 중앙 수직선
   - 좌우 교차 배치되는 연설 아이템
   - 시간 순서 시각화

각 요소에 적절한 트랜지션 효과를 추가해주세요.
```

## 4. 연설 템플릿 페이지 구현 요청

```
speech-template.html 파일에 다음 구조로 연설 상세 페이지 템플릿을 만들어주세요:

1. 헤더 영역:
   - 연설 제목 (h1)
   - 연설자 이름과 연도 (h2)
   - 출처 정보 (p, 작은 글씨)

2. 탭 내비게이션:
   - "역사적 배경" 탭
   - "연설문" 탭
   - "영향과 의의" 탭

3. 콘텐츠 영역:
   - 각 탭에 해당하는 내용 영역
   - 인용문 스타일 (blockquote)
   - 이미지 배치 영역

4. 관련 연설:
   - 같은 시대 또는 주제의 다른 연설 링크

5. 이전/다음 연설 네비게이션

CSS는 클래스 기반으로 작성하고, 실제 내용 대신 "{TITLE}", "{SPEAKER}", "{YEAR}" 등의 플레이스홀더를 사용해주세요.
```

## 5. 실제 연설 페이지 작성 요청 (예시)

```
"I Have a Dream" 연설 페이지를 speech-template.html을 기반으로 다음 정보를 포함하여 생성해주세요:

- 파일명: speeches/i-have-a-dream.html
- 제목: I Have a Dream
- 연설자: 마틴 루터 킹 주니어
- 연도: 1963년
- 출처: 킹 센터 아카이브
- 역사적 배경: [여기에 역사적 배경 텍스트 삽입]
- 연설문: [여기에 연설문 삽입]
- 영향과 의의: [여기에 영향과 의의 텍스트 삽입]
- 관련 연설: "버밍엄 감옥에서의 편지", "베트남 전쟁 반대 연설"

연설문은 단락별로 <p> 태그로 구분하고, 중요 문구는 <strong> 태그로 강조해주세요.
```

## 6. 카테고리 페이지 구현 요청

```
20세기 중반 카테고리 페이지(mid-20th.html)를 다음 구조로 구현해주세요:

1. 카테고리 헤더:
   - "20세기 중반의 명연설" 제목
   - "1940년대부터 1960년대까지, 인류 역사의 중대한 전환점에서 울려퍼진 연설들" 소개문

2. 연설 목록:
   - 이 카테고리에 속하는 10개 연설 카드 형태 나열
   - 각 카드에는 연설 제목, 연설자, 연도, 간략 소개 포함
   - 카드 클릭 시 해당 연설 페이지로 이동

3. 시대적 배경 설명:
   - 이 시기의 주요 역사적 사건과 맥락 소개
   - 추가 참고 자료 링크

반응형 그리드 레이아웃을 적용하여, 화면 크기에 따라 카드가 1열, 2열, 3열로 재배치되도록 해주세요.
```

## 7. 반응형 디자인 구현 요청

```
responsive.css 파일에 다음 화면 크기에 대한 반응형 스타일을 구현해주세요:

1. 모바일 (최대 767px):
   - 단일 컬럼 레이아웃
   - 내비게이션을 햄버거 메뉴로 변경
   - 글자 크기 축소 (본문 14px)
   - 타임라인을 단순화된 세로 목록으로 변경

2. 태블릿 (768px-1023px):
   - 2열 그리드 레이아웃
   - 축소된 여백
   - 일부 장식 요소 간소화

3. 데스크톱 (1024px 이상):
   - 기본 디자인 유지

각 요소의 전환이 부드럽게 이루어지도록 적절한 미디어 쿼리를 사용해주세요.
```

## 8. 인쇄용 스타일 구현 요청

```
print.css 파일에 PDF 변환 및 인쇄에 최적화된 스타일을 구현해주세요:

1. 불필요한 요소 제거:
   - 내비게이션 메뉴, 검색 상자, 소셜 링크 등 숨김
   - 배경색과 배경 이미지 제거

2. 타이포그래피 최적화:
   - 흑백 인쇄에 적합한 색상 대비
   - 인쇄용 서체 (serif 계열 권장)
   - 적절한 글자 크기 (본문 12pt)

3. 레이아웃 조정:
   - 페이지 나눔 최적화 (제목 다음에서 페이지 나눔 방지)
   - 여백 설정 (인쇄 여백 고려)
   - 표와 이미지 크기 조정

4. 추가 기능:
   - 링크 URL 표시 (a 태그 after 사용)
   - 페이지 번호 자동 생성
   - 목차 페이지 스타일링

@media print {} 선택자를 사용하여 인쇄 시에만 적용되는 스타일을 구현해주세요.
```

## 9. 특별 기능 구현 요청

```
다음 기능들을 순수 HTML과 CSS만으로 구현해주세요:

1. 연설 인용구 강조 효과:
   - 중요한 인용구를 시각적으로 돋보이게 하는 스타일
   - 예: 박스 처리, 다른 배경색, 다른 글꼴 크기

2. 탭 전환 시스템:
   - JavaScript 없이 CSS만으로 탭 콘텐츠 전환 기능
   - 라디오 버튼 + :checked 선택자 활용

3. 다크 모드 토글:
   - 사용자가 라이트/다크 모드를 전환할 수 있는 UI
   - localStorage 대신 checkbox + CSS 변수 활용

4. 반응형 이미지 갤러리:
   - 연설자 사진이나 역사적 이미지를 표시하는 갤러리
   - 그리드 레이아웃 기반, 화면 크기에 따라 적응
```

## 10. 콘텐츠 채우기 기본 지침

```
연설 페이지를 채울 때 다음 지침을 따라주세요:

1. 연설 배경 작성 방식:
   - 200-300단어 분량의 간결한 역사적 맥락 설명
   - 핵심 사건과 인물 중심으로 작성
   - 중립적이고 객관적인 톤 유지

2. 연설문 형식:
   - 원문과 번역문 병기 (가능한 경우)
   - 단락 구분 명확히
   - 중요 구절 강조
   - 긴 연설의 경우 핵심 부분 발췌 가능

3. 영향과 의의 작성 방식:
   - 사회적, 정치적, 문화적 영향 설명
   - 현대까지 이어지는 유산 언급
   - 인용과 참고문헌 포함
```

## 12. 테스트 및 검증 방법

```
구현된 각 페이지는 다음 사항을 확인해주세요:

1. HTML 유효성:
   - W3C HTML Validator 통과
   - 의미적 태그 사용 확인

2. CSS 품질:
   - 불필요한 중복 제거
   - 명확한 네이밍 규칙 준수
   - 브라우저 호환성 확인

3. 반응형 테스트:
   - Chrome DevTools 디바이스 모드로 다양한 화면 크기 테스트
   - 실제 모바일 기기에서 테스트

4. 접근성 확인:
   - 색상 대비 충분
   - 키보드 탐색 가능
   - 스크린 리더 호환성
```
