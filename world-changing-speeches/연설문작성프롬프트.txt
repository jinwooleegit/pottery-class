# 연설문 콘텐츠 확보 및 구현을 위한 Cursor AI 프롬프트 가이드

안녕하세요, 이진우님! 연설문 콘텐츠 확보는 매우 중요한 질문입니다. Cursor AI는 2023년 11월까지의 지식을 가지고 있어 대부분의 역사적 연설에 대한 정보를 제공할 수 있습니다. 다음은 Cursor AI를 활용해 연설문 콘텐츠를 확보하고 페이지를 완성하는 프롬프트 가이드입니다.

## 기본 연설문 정보 요청 프롬프트

```
"I Have a Dream" 연설에 대한 다음 정보를 제공해주세요:

1. 연설 기본 정보:
   - 연설자: 마틴 루터 킹 주니어
   - 연설 일자 및 장소: 1963년 8월 28일, 워싱턴 D.C. 링컨 기념관
   - 역사적 맥락: 이 연설이 이루어진 시대적 배경과 사회적 상황

2. 연설문 주요 내용:
   - 원문 발췌(영어): 가장 유명한 구절과 핵심 메시지를 포함한 주요 부분
   - 한국어 번역: 주요 부분의 번역문

3. 연설의 영향과 의의:
   - 당시 사회에 미친 즉각적 영향
   - 장기적 역사적 의의
   - 현대까지 이어지는 유산

가능한 정확하고 검증된 정보를 기반으로 설명해주세요.
```

## 전체 연설문 요청 프롬프트

```
마틴 루터 킹 주니어의 "I Have a Dream" 연설 전문을 영어 원문으로 제공해주세요. 가능하다면 단락별로 구분하여 제공해주세요. 연설문 중 가장 유명하고 중요한 구절에는 <strong> 태그를 사용하여 강조해주세요.
```

## 연설문 번역 요청 프롬프트

```
다음 영어 연설문을 한국어로 번역해주세요. 원문의 수사적 표현과 감동을 최대한 살리면서, 자연스러운 한국어로 번역해주세요:

[영어 연설문 일부 또는 전체 삽입]

번역 시 다음 사항을 고려해주세요:
- 문화적/역사적 맥락을 고려한 적절한 표현 선택
- 원문의 리듬감과 힘을 살리는 번역
- 한국 독자들이 이해하기 쉬운 표현 사용
```

## 연설 배경 자료 요청 프롬프트

```
마틴 루터 킹 주니어의 "I Have a Dream" 연설에 대한 역사적 배경을 다음 구조로 작성해주세요:

1. 미국 시민권 운동의 역사적 맥락 (100-150단어)
2. 워싱턴 행진의 조직과 목적 (100-150단어)
3. 연설이 이루어진 당시의 정치적/사회적 상황 (100-150단어)
4. 연설 준비 과정과 흥미로운 뒷이야기 (100-150단어)

각 섹션이 명확히 구분되도록 작성하고, 사실에 기반한 정보를 제공해주세요.
```

## 연설의 영향 분석 요청 프롬프트

```
마틴 루터 킹 주니어의 "I Have a Dream" 연설이 미친 영향과 의의를 다음 관점에서 분석해주세요:

1. 단기적 영향: 연설 직후와 1960년대 시민권 운동에 미친 영향
2. 장기적 영향: 미국 사회와 정치에 미친 지속적 영향
3. 수사학적/언어적 중요성: 연설의 구조, 비유, 언어적 특징 분석
4. 현대적 의의: 오늘날까지 이 연설이 갖는 중요성과 관련성

각 항목별로 150-200단어 분량으로 작성해주세요.
```

## 연설문 인용구 추출 프롬프트

```
마틴 루터 킹 주니어의 "I Have a Dream" 연설에서 가장 영향력 있고 기억에 남는 인용구 10개를 선별해주세요. 각 인용구에 대해 다음 형식으로 제공해주세요:

1. 영어 원문
2. 한국어 번역
3. 간략한 맥락 설명 (1-2문장)

이 인용구들은 웹사이트의 인용구 강조 섹션과 시각적 요소로 활용될 예정입니다.
```

## 전체 페이지 구현 요청 프롬프트

```
지금까지 수집한 "I Have a Dream" 연설 자료를 바탕으로 완성된 HTML 페이지를 작성해주세요. 다음 요소를 포함해야 합니다:

1. 페이지 기본 구조 (speech-template.html 기반)
2. 연설 기본 정보 (제목, 연설자, 일자, 장소)
3. "역사적 배경" 탭 콘텐츠
4. "연설문" 탭 콘텐츠 (영어 원문 및 한국어 번역)
5. "영향과 의의" 탭 콘텐츠
6. 주요 인용구 강조 섹션
7. 관련 연설 링크

메인 CSS와 반응형 CSS가 적용되도록 적절한 클래스를 사용해주세요.
파일명: speeches/i-have-a-dream.html로 저장될 예정입니다.
```

## 저작권 주의 사항 및 효율적 작업 방법

**저작권 고려사항:**
- 대부분의 역사적 연설문은 공공 도메인이거나 교육적 목적으로 사용 가능합니다
- 각 연설문 출처를 명확히 표기하세요 (연설문 아래 출처 명시)
- 최근 연설(예: 그레타 툰베리)의 경우 Creative Commons 라이선스 확인 필요
- 사진 자료의 경우 가능한 공공 도메인 이미지 사용 권장

**효율적 작업 방법:**
1. 연설문 5-10개를 묶어서 한 번에 정보 요청하기
2. 각 카테고리별로 작업 진행하기 (한 시대를 완성한 후 다음으로 넘어가기)
3. 연설별 폴더 구조 만들기:
   ```
   /research/speech-name/
     - background.md
     - transcript.md
     - impact.md
     - quotes.md
   ```
4. GitHub 이슈를 활용한 진행 상황 추적

**Cursor AI의 제약 사항:**
- 매우 긴 연설문의 경우 여러 부분으로 나누어 요청해야 할 수 있습니다
- 번역 품질을 위해 중요한 부분은 추가 검토가 필요할 수 있습니다
- 2023년 11월 이후의 상세 정보는 부족할 수 있으므로 외부 자료 참조 필요

이 프롬프트 가이드를 활용하면 Cursor AI가 대부분의 연설문 콘텐츠를 제공할 수 있을 것입니다. 작업 중 필요한 부분이 있으면 프롬프트를 조정해 추가 정보를 요청하실 수 있습니다.
